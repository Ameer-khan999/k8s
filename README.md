# ☸️ Kubernetes (K8s) Learning Laboratory & Reference Guide

Welcome to my personal Kubernetes learning repository! This repository serves as a structured, hands-on archive of everything I am learning about Kubernetes—from fundamental concepts and architecture to advanced cluster management, hands-on practice manifests, and real-world deployment patterns.

---

## 📌 Objectives

* **Knowledge Base:** Centralize notes, architectural diagrams, and cheat sheets.
* **Hands-on Labs:** Store reusable YAML manifests and step-by-step practical guides.
* **Best Practices:** Document real-world deployment patterns, security guidelines, and troubleshooting procedures.
